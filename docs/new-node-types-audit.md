# New node types: primary-source audit

- **EasyTier — implemented for mihomo/Clash.** The [mihomo docs](https://wiki.metacubex.one/config/proxies/easytier/) and [v1.19.31 outbound option struct](https://github.com/MetaCubeX/mihomo/blob/v1.19.31/adapter/outbound/easytier.go) agree on the `easytier` YAML shape. `name` and `network-name` are required; `peers` and `listeners` are URI lists, not top-level `server`/`port`. Preserve the YAML options, omit the internal destination placeholders, and skip with diagnostics on other targets.
- **AmneziaWG — implemented for mihomo/Clash; blocked for sing-box.** The [mihomo WireGuard docs](https://wiki.metacubex.one/config/proxies/wg/) and [v1.19.31 core](https://github.com/MetaCubeX/mihomo/blob/v1.19.31/adapter/outbound/wireguard.go) define `wireguard.amnezia-wg-option` (not flat fields), including integer `jc`, `jmin`, `jmax`, `s1`, `s2`, and numeric or string `h1`–`h4` (ranges with v2+). The [sing-box endpoint docs](https://sing-box.sagernet.org/configuration/endpoint/wireguard/) and [v1.14.4 endpoint schema](https://github.com/SagerNet/sing-box/blob/v1.14.4/option/wireguard.go) declare only standard WireGuard; [upstream PR #2670](https://github.com/SagerNet/sing-box/pull/2670) closed unmerged. A released endpoint schema accepting the AmneziaWG fields is missing. Skip rather than silently export plain WireGuard.
- **Sudoku — implemented for the upstream CLI short link (`uri`) and native mihomo YAML; blocked for Shadowrocket.** The [protocol repo's guide](https://github.com/SUDOKU-ASCII/sudoku/blob/b1d1f0e767653d2c70e2ff814a01264c7dedf1f4/doc/getting-started.en.md) and [short-link codec](https://github.com/SUDOKU-ASCII/sudoku/blob/b1d1f0e767653d2c70e2ff814a01264c7dedf1f4/internal/config/shortlink.go) define `sudoku://` + unpadded base64url JSON. [mihomo's Sudoku docs](https://wiki.metacubex.one/config/proxies/sudoku/) separately define the YAML format. Each form stays native; the producer does not assume their defaults are interchangeable. The [Shadowrocket App Store release history](https://apps.apple.com/us/app/shadowrocket/id932747118) lists Sudoku support under 2.2.93 (not 2.2.92); neither those notes nor the [developer's site](https://shadowlaunch.com/) specify an import format. An official Shadowrocket node/config example or explicit confirmation that it imports the upstream CLI short link is missing.
- **Loon Tailscale — implemented.** [Loon's node manual](https://nsloon.app/docs/Node/#tailscale) documents the 3.5.4 (1016) `name = tailscale,auth-key="…",hostname=…` form, with no positional address/port; [the subscription manual](https://nsloon.app/docs/Node/subscription) accepts standard node lines. Reuse the existing `?tailscale=1` gate, decrypted bound key and hostname. Omit the node for unbound users and on name collisions. Do not copy the mihomo-only dialer or inject a Loon policy group/rules; Loon handles MagicDNS routing natively.
